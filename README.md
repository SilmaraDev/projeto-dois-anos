# Projeto Dois Anos

Projeto web desenvolvido para criar uma experiência digital personalizada de comemoração de aniversário de relacionamento.

A página reúne fotos, momentos especiais e uma linha do tempo em uma experiência visual personalizada.

## 🌐 Projeto publicado

**[Acessar o projeto](https://paradaiana.netlify.app/)**

## Funcionalidades

* Galeria de fotos
* Página personalizada
* Linha do tempo de momentos especiais
* Suporte para vídeo
* Layout adaptado para diferentes dispositivos
* Publicação do projeto na web

## Tecnologias

* JavaScript
* Node.js
* Express
* Git
* GitHub
* Netlify
